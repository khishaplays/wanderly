# Wanderly 🌍

**Your intelligent companion for going somewhere new.**

Wanderly is a context-aware global travel planning platform that helps people discover destinations, plan trips, build itineraries, manage budgets, and personalize their experience based on how and why they are traveling.

## Planned Experiences

- ✈️ Leisure travel
- 🧍 Solo travel
- 💑 Couples
- 👨‍👩‍👧 Families
- 👯 Groups
- 🎓 International students
- 💻 Digital nomads
- 🏡 Relocation

## Planned Tech Stack

- React + Vite
- Python + Flask
- MySQL
- REST API
- Pytest
- Vitest / React Testing Library
- GitHub Actions
- Ollama _(future phase)_
