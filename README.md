# Wanderly V1.0 Requirements

## Product Goal

Wanderly V1.0 will provide the core travel-planning experience that allows users to discover destinations, save places, create trips, organize itineraries, and manage estimated travel budgets.

## Core User Journey

Home → Explore → Destination Details → Save/Create Trip → My Trips → Itinerary → Budget

## Core Features

### Authentication

- Register
- Login
- Logout
- User profile
- Protected routes

### Destination Discovery

- Browse destinations
- Search destinations
- Filter destinations
- View destination details
- View available activities

### Saved Destinations

- Save a destination
- View saved destinations
- Remove saved destination

### Trip Management

- Create trip
- View trips
- Edit trip
- Delete trip

### Itinerary

- Add activities to a trip
- Assign activities to days
- Remove activities
- Reorder itinerary items
- Add custom notes

### Budget

- Set target budget
- Track estimated costs
- Group costs by category
- Calculate total estimated cost
- Compare estimated cost against target budget

### Reviews

- Rate destinations
- Write reviews
- View reviews

### Administration

- Add destinations
- Edit destinations
- Delete destinations
- Manage activities
- Moderate reviews
